# Building LumiYi

LumiYi is my personal portfolio website built with modern web technologies.

## Tech Stack

1. **React**: Core library for building interactive user interfaces.
2. **Tailwind CSS**: Utility-first CSS framework for rapid styling.
3. **Framer Motion**: Smooth animations and transitions.
4. **React Router**: Client-side routing and page navigation.

## Why This Tech Stack?

I chose this tech stack because it offers the ideal balance between performance, developer experience, and design flexibility.
